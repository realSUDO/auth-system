OAuth 2.0 Integration Guide

        
SudoAuth implements the OAuth 2.0 Authorization Code flow. To integrate, first request access to get your credentials.

      


      

        
Endpoints

        

          
GET/.well-known/openid-configurationOIDC discovery document

          
GET/jwksPublic keys for token verification

          
GET/oauth/authorizeAuthorization endpoint

          
POST/oauth/tokenToken exchange

          
GET/oauth/userinfoGet user profile (requires token)

          
POST/auth/loginDirect login (first-party apps)

          
POST/auth/signupCreate account

          
GET/auth/verifyVerify a JWT token

        

      


      

        
Step 1 — Redirect user to authorize

        
const url = new URL('https://auth.sudohq.me/oauth/authorize');
url.searchParams.set('client_id', YOUR_CLIENT_ID);
url.searchParams.set('redirect_uri', YOUR_REDIRECT_URI);
url.searchParams.set('response_type', 'code');
url.searchParams.set('state', crypto.randomUUID()); // CSRF protection
url.searchParams.set('email', userEmail);     // collected by your UI
url.searchParams.set('password', userPass);   // collected by your UI

window.location.href = url.toString();
// Redirects to YOUR_REDIRECT_URI?code=...&state=...

      


      

        
Step 2 — Exchange code for token

        
// On your server (never expose client_secret in frontend)
const res = await fetch('https://auth.sudohq.me/oauth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    grant_type: 'authorization_code',
    code: codeFromQuery,
    client_id: YOUR_CLIENT_ID,
    client_secret: YOUR_CLIENT_SECRET,
    redirect_uri: YOUR_REDIRECT_URI,
  }),
});
const { access_token, refresh_token } = await res.json();

      


      

        
Step 3 — Get user info

        
const res = await fetch('https://auth.sudohq.me/oauth/userinfo', {
  headers: { Authorization: `Bearer ${access_token}` },
});
const user = await res.json();
// { sub, email, name }

      


      

        
Step 4 — Refresh the token

        
// access_token expires in 15 minutes
const res = await fetch('https://auth.sudohq.me/oauth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    grant_type: 'refresh_token',
    refresh_token: storedRefreshToken,
    client_id: YOUR_CLIENT_ID,
    client_secret: YOUR_CLIENT_SECRET,
  }),
});
const { access_token, refresh_token } = await res.json();
// refresh_token is rotated on each use

      


      

        
Verify a token (any service)

        
// No database call needed — uses public key from /jwks
const res = await fetch('https://auth.sudohq.me/auth/verify', {
  headers: { Authorization: `Bearer ${token}` },
});
const { valid, decoded } = await res.json();
// decoded.sub = userId, decoded.email, decoded.exp
